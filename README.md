# Portfolio Website | Md Saikot Islam

A high-performance, modern portfolio website built with **Next.js 15+**, **Tailwind CSS**, and **Framer Motion**. This project serves as a digital showcase of my technical journey, projects, skills, and professional experience.

## 🚀 Key Features

* **Modern Design:** Clean, glassmorphic aesthetic using Tailwind CSS and HeroUI.
* **Smooth Animations:** Dynamic entrance effects and scroll-triggered transitions powered by Framer Motion.
* **Performance Focused:** Built with the Next.js App Router for optimal SEO and loading speed.
* **Dark/Light Mode:** Seamless theme switching with system-preference detection.
* **Interactive Components:** Custom skill progress indicators and responsive project galleries.

## 🛠 Tech Stack

| Category | Technology |
| :--- | :--- |
| **Framework** | Next.js (App Router) |
| **Styling** | Tailwind CSS |
| **UI Components** | HeroUI |
| **Animations** | Framer Motion |
